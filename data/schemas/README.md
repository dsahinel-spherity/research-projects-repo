# Official StanForD schemas

The HPR schemas and their common-definition dependencies are retained unmodified from Skogforsk's released schema archives (versions 2.1, 3.2, 3.3, 3.6 and 4.1). All other files from the archives are omitted because HPR validation does not need them.

Source: https://www.skogforsk.se/english/projects/stanford/stanford-2010/

- https://www.skogforsk.se/contentassets/1a68cdce4af1462ead048b7a5ef1cc06/stanford2010_release_3.3.zip
- https://www.skogforsk.se/contentassets/1a68cdce4af1462ead048b7a5ef1cc06/stanford2010_release_4.1.zip

Downloaded 2026-10-26. Validation runs locally with external network resolution disabled. XSD validation and XML extraction are separate: a vendor extension can be extracted while producing official-schema findings. Recovered fragments are never labeled as schema-valid complete documents.
